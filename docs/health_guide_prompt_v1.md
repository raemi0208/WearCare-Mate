# 건강 가이드 프롬프트 (Bedrock) - 테스트 기록

- 작성: 조채환 (AI/ML 파트) / 2026-10-22
- 환경: Amazon Bedrock Playground (서울 리전, ap-northeast-2 확인함. SageMaker 노트북도 서울)
- 상태: v1, v2 테스트 완료, v3는 조건 불량(대화 기록 섞임), v3.1 테스트 완료, v6 테스트 완료 -> **확정 (Haiku 4.5, 케이스 A~D 기준)**. 남은 일: 모델 비교, 더 많은 입력, 실제 API(converse) 호출 검증

## v1 (초안) - 테스트 완료

```
너는 웨어러블 데이터를 바탕으로 건강 습관을 안내하는 도우미야.
의학적 진단이나 약 처방은 절대 하지 말고, 일상에서 할 수 있는 행동만 제안해.
증상이 심하거나 지속되면 전문가 상담을 권하는 문장을 마지막에 한 줄 넣어.
말투는 친근하고 간결하게, 3줄 이내로 써.

[오늘의 이상 징후]
- 안정시 심박: 78bpm (평소 64bpm, 평소보다 +14)
- 수면 시간: 4.8시간 (평소 7.0시간)
- 걸음 수: 2,100보 (평소 7,500보)
```

2. 입력에 없는 **시점을 단정**: 입력은 "오늘"인데 응답이 "어제"라고 표현
