# 웨어케어 메이트 (WearCare Mate)
> 웨어러블 기반 AI 건강 주치의: 웨어러블 시계열 데이터 분석 및 생성형 AI 기반 개인 맞춤형 건강 행동 가이드 서비스

## 01. 프로젝트 배경 및 필요성
- **데이터 홍수 속 인사이트 부재 및 단순 수치 제공의 한계**
  - 현대인의 필수품이 된 웨어러블 기기는 수면, 심박, 활동량 등 방대한 건강 데이터를 수집하고 있으나, 대다수의 서비스는 단순 수치 나열에 그쳐 사용자가 데이터의 진정한 의미를 이해하고 대처하기 어렵습니다.
- **개인 맞춤형 케어 필요성**
  - 개인의 평소 생활 패턴을 학습하여 미세한 이상 징후를 실시간으로 탐지하고, 생성형 AI를 통해 사용자 눈높이에 맞는 전문적이고 친근한 건강 행동 가이드를 제공함으로써 주도적인 건강 관리를 돕고자 합니다.

---

## 02. 핵심 기능
1. **데이터 수집 및 저장**
   - 공개/오픈 웨어러블 데이터셋을 Amazon S3에 적재하고, Amazon Timestream을 통해 시계열 데이터를 효율적으로 관리.
2. **AI 이상 패턴 탐지**
   - 사용자별 평소 생활 패턴을 학습하여 수면·심박·활동량의 이상 징후(Anomaly)를 정확하게 감지 (Amazon SageMaker 활용).
3. **맞춤형 가이드 생성**
   - 탐지된 데이터를 바탕으로 생성형 AI(Amazon Bedrock)가 맞춤형 행동 가이드를 생성하고, 웹 대시보드(AWS Amplify)를 통해 실시간 제공.

---

## 03. 파트별 역할 분배
- **데이터 & 파이프라인**
  - 공개 데이터셋 탐색, Amazon S3 원본 적재, AWS Lambda 전처리, Amazon Timestream 시계열 DB 구축.
- **AI 모델 & 생성형 AI**
  - Amazon SageMaker 이상 패턴 탐지 모델 구현, Amazon Bedrock 기반 개인 맞춤형 행동 가이드 프롬프트 엔지니어링.
- **백엔드 & 프론트엔드**
  - API Gateway + Lambda API 구축, Amazon SNS 알림 연동, AWS Amplify 기반 웹 대시보드 UI 구현.

---

## 04. 시스템 아키텍처 및 기술 스택
- **STEP 1 (데이터 수집 및 저장):** 웨어러블 기기 데이터셋 S3 적재 및 Lambda 전처리
- **STEP 2 (시계열 저장 및 이상 탐지):** Amazon Timestream 저장 및 SageMaker 평소 패턴 학습/이상 탐지
- **STEP 3 (AI 가이드 생성):** 감지된 이상 패턴을 바탕으로 Amazon Bedrock이 맞춤형 행동 가이드 생성
- **STEP 4 (알림 및 웹 서빙):** SNS 푸시 알림 발송 및 AWS Amplify 웹 대시보드를 통한 결과 확인

---

## 05. 개발 로드맵
- **1단계: 데이터 수집 및 파이프라인 구축**
  - 공개 웨어러블 데이터셋 탐색 및 선정, Amazon S3 원본 데이터 적재 및 AWS Lambda 기반 전처리 자동화 구현
- **2단계: 시계열 DB 및 AI 모델 학습**
  - Amazon Timestream 시계열 DB 테이블 설계 및 데이터 적재, Amazon SageMaker를 활용한 개인별 평소 패턴 학습 및 이상 패턴(Anomaly) 탐지 모델 구현
- **3단계: 생성형 AI 및 백엔드 연동**
  - Amazon Bedrock 기반 개인 맞춤형 행동 가이드 생성 프롬프트 및 로직 연동, Amazon API Gateway + Lambda를 통한 REST API 구축 및 SNS 푸시 알림 연동
- **4단계: 웹 서비스 구현 및 통합 테스트**
  - AWS Amplify를 활용한 건강 대시보드 및 AI 가이드 확인 웹 UI 배포, 전체 시스템 연동 테스트 및 최종 검증 완료
